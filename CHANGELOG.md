# Changelog

## 0.1.0

- Initial implementation of the QPV security simulator.
- Deterministic discrete-event core and optional SeQUeNCe 1.0.0 adapter.
- Timed QND, memory, measurement, and local-clock models.
- Schedule skew, telemetry poisoning, timestamp forgery, selective jamming,
  and intercept-measure-resend attacks.
- CLI, reproducible outputs, tests, examples, and tutorials.
